# 一目均衡表圖表使用說明

這個畫面用一目均衡表判斷趨勢環境與價格平衡，再用 CMF 確認資金方向。建議依照「雲層 → 基準線 → 轉換線 → CMF」的順序閱讀，不要只靠單一交叉決定買賣。

## 1. 畫面上的線代表什麼？

| 畫面元素 | 顏色 | 主要用途 |
| --- | --- | --- |
| 雲層 | 中性灰藍色 | 判斷價格所在的趨勢環境與可能較難穿越的區間 |
| 基準線 | 金黃色 | 最近 26 期的中期平衡位置 |
| 轉換線 | 淺藍色 | 最近 9 期的短期動能 |
| CMF | 白色 | 判斷資金偏流入或流出 |
| CMF EMA | 橘色虛線 | 觀察資金動能正在增強或減弱 |

遲行線目前隱藏，避免主圖線條過多。

## 2. 建議判讀順序

### 第一步：先看價格和雲層

| 價格位置 | 解讀 |
| --- | --- |
| 雲層上方 | 整體結構偏多 |
| 雲層內 | 方向不明，容易震盪 |
| 雲層下方 | 整體結構偏空 |

雲層統一使用中性色，避免把 A、B 線排列誤認成價格方向。判斷重點是價格在雲上、雲內或雲下。

### 第二步：看價格和基準線

| 價格位置 | 解讀 |
| --- | --- |
| 基準線上方 | 短中期動能偏強 |
| 基準線附近 | 接近中期平衡 |
| 基準線下方 | 短中期動能偏弱 |

基準線走平代表最近 26 期的價格區間沒有明顯推進，常見於盤整或價格回測區。

### 第三步：看轉換線和基準線的距離

系統使用 ATR(14) 標準化不同股票與週期：

TK 距離 =（轉換線－基準線）÷ ATR(14)

| TK 距離 | 解讀 |
| --- | --- |
| 絕對值 < 0.25 ATR | 兩線糾纏，短線方向不明 |
| 0.25～0.75 ATR | 一般短期動能 |
| 絕對值 > 0.75 ATR | 動能明顯，但也要留意價格回歸基準線 |

- 數值為正：轉換線在基準線上方，短期偏強。
- 數值為負：轉換線在基準線下方，短期偏弱。
- 轉換線在上且距離擴大：多方動能增強。
- 轉換線在上但距離縮小：留意多方動能減弱。
- 轉換線在下且距離擴大：空方動能增強。
- 轉換線在下但距離縮小：留意空方動能減弱。
- 上穿基準線稱為 TK 金叉，下穿稱為 TK 死叉；雲層內的交叉較容易失效。

這些距離門檻是畫面判讀用的經驗區間，不是一目均衡表的固定官方參數，也不是獨立買賣訊號。

### 第四步：看雲層厚度

雲層厚度同樣以 ATR(14) 判斷：

| 雲層厚度 | 解讀 |
| --- | --- |
| < 0.5 ATR | 薄，較容易被價格穿越 |
| 0.5～1 ATR | 一般 |
| > 1 ATR | 厚，價格通常較難一次穿越 |

厚雲不是一定守住，薄雲也不代表一定突破；它只描述價格穿越該區間的相對難度。

### 第五步：用 CMF 確認

| CMF 狀態 | 解讀 |
| --- | --- |
| CMF > 0 | 資金偏流入 |
| CMF < 0 | 資金偏流出 |
| CMF 與 EMA 同時向上 | 資金動能增強 |
| CMF 與 EMA 同時向下 | 資金動能減弱 |

CMF 是確認工具。價格在雲上但 CMF 持續轉弱時，仍要留意動能退潮。

## 3. 常見組合

| 畫面狀態 | 較合理的解讀 |
| --- | --- |
| 雲上＋價格在基準線上＋TK 正距離擴大 | 多頭結構與短期動能一致 |
| 雲上＋跌破基準線＋TK 距離縮小 | 多頭環境中的回檔或轉弱 |
| 雲內＋兩線糾纏 | 盤整，交叉訊號可信度較低 |
| 雲下＋價格在基準線下＋TK 負距離擴大 | 空頭結構與短期動能一致 |
| 雲下＋突破基準線 | 先視為反彈，站上雲層後才算結構改善 |

## 4. 26 期後雲層

右側沒有 K 棒的雲層，是把目前算出的雲層向右移動 26 期。畫面不再顯示或評分 A／B 線排列，只保留真正容易使用的資訊：

- 上緣與下緣形成的價格區間。
- 以 ATR 正規化後的相對厚度。
- 雲層正在變厚、變薄或變化不大。

區間越厚，價格通常越難一次穿越；區間越薄，穿越難度通常較低。上、下緣仍只是區間參考，不是目標價。

最重要的是：**26 期後雲層是結構參考，不是價格預測。**

## 5. 使用限制

- 一目均衡表在日線與週線通常比短週期穩定。
- 小時線容易出現更多交叉與雜訊，應提高對雲層位置及 CMF 確認的要求。
- 未來日期目前會排除週末，但沒有接入台股國定休市日曆。
- 所有文字均為技術結構說明，不構成買賣建議。
